# Venkat Ramana Nemani — Data Analyst Portfolio

A responsive portfolio customized from the supplied theme for Venkat Ramana Nemani. Content is based on the uploaded résumé.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev` and open the local URL shown by Vite.

## Build

`npm run build`

## Update portfolio content

Edit `src/data/portfolio.ts` for profile details, skills, projects, experience and certifications.

## Resume

The PDF is served from `public/assets/Venkat_Nemani_Resume.pdf`.
